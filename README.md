# PoE 2 Build Nexus

Live repository for the PoE 2 Build Nexus / Atziri Temple Planner.

**Current published Temple release: V8.10**

This repository is set up for static deployment on Vercel. The production `index.html` is a compact loader containing the complete V8.10 planner payload, including the manual six-card Live Hand, beginner-friendly connection rendering, and PoE2DB Temple room icons.

Future releases can be published by updating this repository and redeploying the same Vercel project.
